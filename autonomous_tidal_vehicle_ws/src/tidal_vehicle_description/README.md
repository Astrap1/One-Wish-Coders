# `tidal_vehicle_description`

The air-cushion vehicle's description. See [`docs/VEHICLE_SIMULATION.md`](../../../docs/VEHICLE_SIMULATION.md).

- `models/hovercraft_v2/`, `urdf/hovercraft_v2.urdf` — **Version 2** (tracked, the demo vehicle), generated by `scripts/gen_description_v2.py` after `assets/vehicle_blender/version_2/build_vehicle.py`
- `models/hovercraft/` — Version 1 Gazebo model (`model.sdf`, `model.config`), Blender-exported meshes and `link_frames.json`
- `urdf/hovercraft.urdf` — ROS robot description with the same links and joints (for `robot_state_publisher`, RViz and Foxglove)
- `scripts/gen_description.py` — regenerates both from `link_frames.json`. Run it after `assets/vehicle_blender/version_1/build_vehicle.py`. Never edit the generated files by hand.
- `config/sensors.yaml` — sensor frames, topics and rates
- `rviz/hovercraft.rviz` — RViz view (Fixed Frame `map`)

Frames: `base_link` (hull), `lidar_link`, `camera_link`, `imu_link`, plus the moving parts: Version 2 `track_left`, `track_right`, fans and rudders; Version 1 `wheel_leg_*`, `wheel_shock_*`, `wheel_*`, fans and rudders.
